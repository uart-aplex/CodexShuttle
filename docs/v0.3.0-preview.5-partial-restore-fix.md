# Preview.5: Failed Copy and Conversation Path Recovery

## Incident

A FullProfile restore copied most of the Codex profile but Robocopy returned exit code 11 with one failed file. RestoreService returned immediately, before automatic conversation-path repair or general profile remapping. A subsequent manual repair corrected 142 index entries. This is an early-return gap in the copy-failure path, not evidence that the destination user root was selected incorrectly.

The failed-byte count matched a browser plugin executable. Plugin host processes were present when investigated, but the previous log discarded the original localized error. A sharing violation is a plausible cause, not a confirmed reconstruction of the original error.

## Changes

- Check running executable paths against every planned destination before copying, including background plugin hosts and Shuttle itself. Block with process IDs and paths; never terminate processes automatically. This is an executable-path preflight, not a complete open-handle scanner; inaccessible processes, non-executable locks and writers that start later can still cause failures.
- If copying has started inside Codex Home and fails, attempt limited index-path recovery only when the package and destination have exactly matching conversation file sets and SHA-256 contents. Compare sessions, archived sessions, state/history database families (including WAL/SHM/journal), session index and reconciliation marker. Reject missing, changed, extra or linked history files before repair. Inspect SQLite only through temporary inspection copies until intentional destination repair.
- Recheck running target executables, validate all indexed paths, perform the same index repair as the manual button, and strictly validate the saved paths afterward. Cancellation skips or stops recovery. The original copy failure remains a failure even if index recovery succeeds; general configuration, working-directory and tool-path conversion is not claimed complete.
- Retain English and Chinese Robocopy error lines plus surrounding context separately from the bounded output tail. Persist localized copy/skip/failure summaries as well.

## Verification

Regression tests use isolated temporary profiles. They cover a real Robocopy sharing violation on a plugin file with plain/compressed rollout filenames, failed conversation copying, mismatched/missing transcripts, unexpected WAL, preflight blocking before overwrite, sibling path boundaries, and localized diagnostics surviving thousands of later output lines. No production restore or production database repair is performed during development.

## Recovery and Handoff

Do not delete the USB package, regenerate its checksums, or treat successful path repair as a complete restore. Existing preview.4 packages remain usable if package validation passes. Close Codex and any identified browser/plugin hosts before retrying. Keep the incoming backup separate from a backup of new destination work.

Run the fixed executable outside all selected restore targets, such as a dedicated local user safety folder or a USB tools folder outside the package. Preserve source changes and this report before another replacement restore: that operation can replace this repository as well as local conversations. GitHub source history does not preserve conversations. Preview.5 does not add safe merge support for compressed or paginated histories.
